# 提词器

一个打开就能用的网页提词器：把稿子贴进去就开始滚动，按每句的字数自动控速。

在线使用：

- 国内访问：<https://xyme.site/prompter/>
- GitHub Pages：<https://zoey1108.github.io/Prompter/>

两个地址是同一个页面，但稿子分开存，在一个地址里存的稿子另一个看不到。

不用注册，没有广告，也不联网保存。稿子和录的视频都只在你自己的浏览器里，不会上传到任何地方。

## 能做什么

- **换稿**：在页面上直接按 ⌘V 或 Ctrl V 粘贴，或者把 `.txt`、`.md` 文件拖进来。也可以点「＋ 新稿」手动新建。
- **存多篇**：顶部下拉框切换。删除要连点两次，防止误删。
- **按字数控速**：每句话按字数分配时间，长句走慢，短句走快。设定好每分钟念多少字就行，默认 270 字/分。
- **估时长**：编辑时实时显示字数和预计时长，压时长不用另外掐表。
- **镜头模式**：摄像头画面垫在稿子下面，边看稿边录，录好直接存成视频。见下面「镜头模式」。
- **背景颜色和补光环**：背景可选深灰、纯黑、深蓝、米白、纯白。补光环有两种形状：方框是屏幕四周一圈白光，圆环是屏幕正中一个发光的圆圈，像环形补光灯。宽度可以自己调：打开补光后，控制栏会出现「补光宽度 − +」，也可以按 [ 和 ] 微调。圆环的大小在「更多」里调。有冷白、纯白、暖光三种颜色，对着脸录的时候能补光，镜头模式下也能用。按 L 开关。
- **录制用的设置**：字号、每行字数、阅读线位置都能调。还有镜像翻转（配反光玻璃提词器）、开头倒数 3 秒、全屏和防止熄屏。

## 镜头模式：边看稿边录

点顶部的「镜头模式」，允许使用摄像头和麦克风以后，摄像头画面会铺在稿子下面，字浮在画面上，像手机拍摄 App 里的提词器。

- **看着镜头念**：笔记本的摄像头在屏幕顶上，把「阅读线位置」调到 15% 到 20%，眼睛就离镜头很近。字号调小一点、每行字数调多一点，不容易挡脸。
- **画面压暗**：在「更多」里调。压暗一点字更清楚，调到 0 就是原始画面。
- **直接录**：点「● 录制」，开了倒数就先倒数 3 秒，然后稿子开始滚、视频开始录。点「■ 停止录制」或按 R 结束。录制中暂停滚动不会停录。
- **保存**：每录一条，右下角会多一条，点「保存」下载到电脑。新版 Chrome、Edge、Safari 存出来是 mp4，旧版浏览器是 webm。
- **录下来的视频**：是摄像头的原始画面，不带提词文字，也不镜像。预览镜像只是为了看着顺手。
- **多台摄像头、外接麦克风**：在「更多」里切换。
- **脸太暗**：在「更多」里打开补光环，把宽度调大，再把屏幕亮度开到最高。

视频只在页面里，没有上传，关掉或刷新页面之前记得保存。

如果你习惯用别的软件录（比如 OBS、剪映、QuickTime），关掉镜头模式，把提词器窗口缩小放在屏幕顶部摄像头下面就行。网页没办法做成透明窗口盖在其他软件上面。

## 稿子怎么写

一行一句，每行之间会稍微停一下。

```
【开场】
画面：产品放在桌上，镜头慢慢推近
早上泡的咖啡，到中午就凉了，这事你应该碰到过。
这是我们新出的一款保温杯。
【结尾】
价格和购买方式，我放在简介里了。
```

- `【开场】` 这样单独占一行的，是段落名，不用念。
- 以 `画面：` 或 `镜头：` 开头的，是拍摄提示，也不用念。录的时候可以按 H 隐藏。
- 直接贴 Markdown 也行，`#` 标题会当成段落名，`**` 加粗和列表符号会自动去掉。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 开始 / 暂停 |
| ↑ ↓ | 语速加快 / 放慢 |
| + − | 字号放大 / 缩小 |
| Home | 回到开头 |
| E | 改稿 |
| H | 显示 / 隐藏画面提示 |
| M | 镜像翻转 |
| F | 全屏 |
| C | 打开 / 关闭镜头模式 |
| L | 打开 / 关闭补光环 |
| [ ] | 补光环调窄 / 调宽 |
| R | 开始 / 停止录制（镜头模式下） |
| ⌘ / Ctrl + Enter | 在编辑框里保存 |

点稿子任意位置也能开始或暂停，滚轮和手指可以随时拖动。

## 离线使用

整个工具就是一个 `index.html`，没有依赖，也不用构建。下载这个文件，双击用浏览器打开就能用，断网也行。断网时字体会退回系统自带的中文字体。镜头模式在本地文件里有的浏览器会拦着不让用摄像头，碰到了就用在线版。

注意：稿子存在打开它的那个浏览器里。在线版和本地文件版的稿子互不相通，换浏览器或清除网站数据之后也会看不到。重要的稿子请自己另存一份，编辑框里有「复制全文」。

## 自己部署

把 `index.html` 放到任何静态网站托管上都行，比如 GitHub Pages、Cloudflare Pages、自己的服务器。
